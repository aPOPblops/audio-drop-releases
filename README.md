# Audio Drop releases

Updates install automatically from inside Audio Drop. This page is for reinstalling a
specific version by hand, for example if an update causes a problem.

How to go back to an earlier version:

- macOS: quit Audio Drop, download the zip above, unzip it and drag Audio Drop into Applications, replacing the current one.
- Windows: quit Audio Drop, download the zip above and unzip it over your Audio Drop folder (or into a new folder).
- Linux: download the tar.gz above and extract it over your Audio Drop folder.

Your library, settings and license are stored separately and are kept.

Older builds than these are removed; all releases: https://github.com/aPOPblops/audio-drop-releases/releases
